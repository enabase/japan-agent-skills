### 🎯 次期スキル開発用：Deep Research コピー＆ペースト用プロンプト

これらは、今後メタスキル `jp-deep-research-workflow` やGrok 3等に入力して「仕様書（Markdown）」を生成するためのプロンプトです。

<details>
<summary><b>1. 営業メール・提案書パーソナライズ自動生成</b></summary>

```markdown
【目的】
BtoB新規営業において、相手企業のWebサイト情報から「自社商材と結びついた、無視されない仮説提案型営業メール」を生成するためのAIエージェントの仕様書（ガイドライン）を作成したい。

【調査項目】
1. 営業メールの返信率が上がる（または下がる）具体的な要因・定量データ（件名、文字数、企業固有の言及など）
2. 「仮説提案型」営業メールの成功事例とテンプレート・フレームワーク（3パターン以上）
3. AIが相手企業サイトから読み取るべき「刺さるポイント」を抽出する具体的なプロンプト・ロジック
4. スパム認定を避けるための特定電子メール法や配信ルールの法的・システム的注意点

【出力形式】
全てMarkdown形式で出力し、この資料一つでAIエージェントの処理設計が完了する「完全仕様書」にしてください。
```
</details>

<details>
<summary><b>2. SNS投稿カレンダー＆原稿フルオート生成</b></summary>

```markdown
【目的】
整体院・美容室・飲食店などの個人事業主向けに、SNS（Instagram/X）の「1ヶ月分の投稿カレンダー」と「バズる型に沿った具体的な投稿文面・ハッシュタグ」を自動生成するAIエージェントの仕様書を作成したい。

【調査項目】
1. 中小店舗におけるSNS運用の「失敗理由」と「効果が出るまでの期間・行動量」のデータ
2. InstagramおよびX（Twitter）における、アルゴリズム上有利になる投稿の「型（フレームワーク）」（例：有益情報、ビフォーアフター、自己開示など）
3. 生成AIに「1ヶ月分のカレンダー（週3〜4回投稿）」を破綻なく設計させる効果的なプロンプト・構成案
4. エンゲージメントを高めるハッシュタグ戦略と、炎上回避・コンプライアンス上の注意事項

【出力形式】
全てMarkdown形式で出力し、この資料一つでAIエージェントの処理設計が完了する「完全仕様書」にしてください。
```
</details>

<details>
<summary><b>3. 24時間 AIボイスボット（電話一次対応）シナリオ設計</b></summary>

```markdown
【目的】
不動産管理・クリニック・飲食店など、電話対応で人員が取られる中小企業向けに、「24時間対応AIボイスボット（電話一次受付）」の応答シナリオとシステム用プロンプトを構築するエージェントの仕様書を作成したい。

【調査項目】
1. 中小企業における電話対応の現状（時間的コスト、取りこぼしによる機会損失）とボイスボット導入のROI
2. 音声AI特有の課題（タイムラグ、誤認識、感情への配慮）とその回避策・プロンプトへの組み込み方
3. 業種別（不動産、医療、飲食など）の電話一次対応の成功台本パターン・分岐シナリオモデル（フローチャート言語化）
4. AIが「どうしても対応できない」と判断し、人間にエスカレーションさせる（転送または折り返し予約）べき判断基準

【出力形式】
全てMarkdown形式で出力し、この資料一つでAIエージェントの処理設計が完了する「完全仕様書」にしてください。
```
</details>
