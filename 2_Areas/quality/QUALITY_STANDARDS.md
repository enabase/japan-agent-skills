# 品質管理基準

## スキルリリース前チェックリスト

### 仕様準拠チェック
- [ ] `name` が小文字英数字・ハイフンのみで1-64文字以内
- [ ] `name` がディレクトリ名と完全一致
- [ ] `description` が1-1024文字以内
- [ ] `description` に「何をするか」と「いつ使うか」の両方が含まれている
- [ ] `description` がやや"pushy"（積極的にトリガーされるように）
- [ ] SKILL.md本体が500行以下
- [ ] 500行を超える場合、references/ に分割されている
- [ ] Progressive Disclosure の3層構造が守られている

### コンテンツ品質チェック
- [ ] 指示が命令形（imperative）で書かれている
- [ ] 具体的な入出力例が含まれている
- [ ] エッジケースへの対処が記述されている
- [ ] セキュリティリスクがないことを確認
- [ ] 悪意のあるコードが含まれていないことを確認

### 日本語品質チェック
- [ ] 敬語レベルが適切で一貫している
- [ ] 専門用語が正確に使用されている
- [ ] 文化的に不適切な表現がない
- [ ] 読みやすさ（文の長さ、句読点）が適切

### テスト
- [ ] evals/evals.json にテストケースが2つ以上含まれている
- [ ] テストケースが現実的なユーザー入力を反映している
- [ ] 期待される出力が明確に定義されている
