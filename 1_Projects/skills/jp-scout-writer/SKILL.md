# 採用スカウトメール＆求人票 自動生成エージェント

このスキルは、採用担当者が「100通送っても返信3通」の壁を突破するための、
媒体別に最適化されたスカウトメールと、応募率を最大化する求人票を自動生成します。

## ワークフロー

### Step 1: ルールベースのロードとヒアリング
`references/scout-guidelines.md` をロードし、媒体別テンプレート・返信率データ・NG表現リスト・レジュメ分析フレームワーク・法令遵守チェックリストをコンテキストに取り込む。

ユーザーに以下をヒアリングする（不足分のみ質問）：
1. **生成対象**: スカウトメール / 求人票 / 両方
2. **送信媒体**: Wantedly / ビズリーチ / Green / LinkedIn / リクナビNEXT・doda
3. **募集ポジション**: 職種名・チーム構成・裁量の範囲・技術スタック
4. **自社の魅力**: 年収レンジ・Working条件・成長環境・ミッション
5. **候補者のレジュメ**（スカウトの場合）: テキストを貼り付けてもらう
6. **送信者情報**: 名前・役職（人事 / 現場マネージャー / CTO / 社長）

### Step 2: 候補者レジュメの5軸分析（スカウトメールの場合）
レジュメが提供された場合、以下の5軸で分析する：
- **① 直近の職種・役割** → 現在地の確認
- **② 転職回数・在籍期間** → 転職意欲の推測（3年未満の短期が続く＝高意欲）
- **③ スキルギャップ** → 「やりたいけどできていないこと」の推測
- **④ キャリア方向性** → 上昇志向 / 安定志向 / 専門深化
- **⑤ 裏の退職理由推測** → 残業多い→WLB訴求、年功序列→裁量訴求、歯車感→0→1訴求

分析結果から「この候補者に最も刺さる自社の魅力TOP3」を選定し、根拠とともに提示する。

### Step 3: スカウトメール生成
媒体別テンプレートに基づき、以下の6要素で構成されたスカウトメールを生成する：
- **① 件名（2パターン）**: A: 条件訴求型（数字入り）/ B: 共感訴求型。25文字以内。
- **② 冒頭1行**: 候補者の具体的な実績やスキルに言及（「ご経歴を拝見し〜」は絶対禁止）
- **③ 自社の魅力**: Step 2で選定したTOP3を候補者の推定不満と紐づけて訴求
- **④ ポジション概要**: 職務内容・チーム・裁量を具体的に
- **⑤ 次のアクション**: 「カジュアル面談・30分・選考ではない」でハードルを下げる
- **⑥ 署名**: 人間味のある一言を添える

**文字数**: 400〜800文字以内（3000文字超は返信率ほぼ0%）

### Step 4: 求人票生成（求人票の場合）
応募率を最大化する構造で求人票を生成する：
- **タイトル**: 35文字以内、環境・条件の差別化ポイントを含める
- **仕事内容**: 1日の流れ / 使用ツール / チーム構成 / 裁量 / 成長パスの5要素必須
- **給与**: 実績値（月給レンジ+前年度賞与実績の月数）。「給与：要相談」は絶対NG
- **ファーストビュー最適化**: 重要情報を上部に集中（50%地点で半数離脱のため）

### Step 5: 法令チェック＆送信前レビュー
生成したメール・求人票に以下のチェックを実施：
- **年齢差別**: 「35歳以下」「若い人が活躍中」→ NG
- **性差別**: 「主婦歓迎」「ママさん活躍中」→ NG
- **障害者差別**: 「体力に自信のある方」→ 具体的な業務内容に置き換え
- **個人情報保護法**: レジュメ情報の採用目的外利用の禁止
- **送信タイミング推奨**: 媒体別の最適曜日・時間帯を提案

## Examples

**Example 1: ビズリーチ向けスカウトメール**
Input: 「ビズリーチで経理マネージャーを採用したい。年収600〜800万円。フルリモート可。候補者は大手メーカーで経理10年、直近は課長職。」
Output: Step 2で「大手10年→年功序列への不満可能性」「課長職→裁量拡大志向」と分析。件名A「年収800万円＋フルリモート｜経理マネージャー」、件名B「大手での経験を、自分の裁量で活かせる環境があります」の2パターン。本文は候補者の大手での経理経験に具体的に言及した冒頭→フルリモート＋裁量訴求→カジュアル面談誘導の構成で600文字以内。送信タイミング「火or木の12〜13時」を推奨。

**Example 2: Wantedly向け求人票**
Input: 「TypeScript/Next.jsのフロントエンドエンジニアをWantedlyで募集したい。5人チーム、技術選定に参加可能、残業月10h以下。」
Output: タイトル「自社開発／TypeScript×Next.js／技術選定に参加できる環境」。仕事内容に1日の流れ（10時出社→スタンドアップ→開発→15時レビュー→17時退勤）、技術スタック、チーム構成（エンジニア5名・平均年齢31歳）、裁量（技術選定・アーキテクチャ設計に参加）、成長パス（3ヶ月→独立開発、6ヶ月→技術リード補佐）を含む。NG表現チェック済。

## Guidelines
- **「ご経歴を拝見し〜」で始まるスカウトメールは絶対に生成しないでください。** これは返信率を最も下げるNG表現の筆頭です。
- 文字数は400〜800文字厳守。3000文字超のスカウトメールは返信率がほぼ0%です。
- 「面接」という単語をスカウトメールで使わないでください。代わりに「カジュアル面談」「30分お話ししませんか」を使用すること。
- 求人票の給与欄に「要相談」と書かないでください。必ず月給レンジと賞与実績を記載すること。
- 年齢・性別・障害に関するNG表現は法令違反です。生成時に自動チェックしてください。
