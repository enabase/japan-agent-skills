# インボイス制度対応チェッカー

日本の適格請求書等保存方式（インボイス制度）に基づき、
請求書の法的要件充足を自動チェックし、不備があれば修正提案を出力する。

## 背景

2023年10月1日より施行されたインボイス制度では、仕入税額控除を受けるために
「適格請求書（インボイス）」の保存が必要。適格請求書には法定の記載事項がある。

## ワークフロー

### Step 1: 入力の受け取り

ユーザーからの入力は以下のいずれか：
- 請求書のテキスト内容
- 請求書のチェック依頼（記載事項を口頭で説明）
- 新規請求書の作成依頼

### Step 2: 必須記載事項のチェック

適格請求書（インボイス）には以下の **6つの必須記載事項** がある。
各項目の有無をチェックし、結果を出力する。

| No. | 必須記載事項 | チェック内容 |
|-----|------------|------------|
| ① | **発行者の氏名・名称** | 事業者名が記載されているか |
| ② | **適格請求書発行事業者の登録番号** | 「T」+13桁の数字（T1234567890123）形式か |
| ③ | **取引年月日** | 日付が明記されているか |
| ④ | **取引内容（軽減税率の対象品目である旨）** | 品目名と、軽減税率対象品には「※」等の印があるか |
| ⑤ | **税率ごとに区分した対価の額（税抜or税込）及び適用税率** | 10%と8%が分けて記載されているか |
| ⑥ | **税率ごとに区分した消費税額** | 税率ごとの消費税額が記載されているか |
| - | **交付を受ける事業者の氏名・名称** | 宛名が記載されているか |

### Step 3: 登録番号のバリデーション

登録番号は以下のルールで検証する：
- 「T」で始まること
- 「T」の後に13桁の半角数字が続くこと
- 法人の場合: T + 法人番号（13桁）
- 個人の場合: T + 新規付番の13桁

フォーマット: `T1234567890123`

> **注意**: このスキルはフォーマットの検証のみ行う。
> 実際の登録番号の有効性確認は [国税庁の公表サイト](https://www.invoice-kohyo.nta.go.jp/) で行う必要がある旨を必ずユーザーに伝えること。

### Step 4: 消費税計算チェック

以下のルールに基づいて消費税の計算を検証する：

- **端数処理**: 1つのインボイスにつき、税率ごとに1回のみ端数処理を行う
- **端数処理方法**: 切捨て・切上げ・四捨五入のいずれかを事業者が選択可（統一が必要）
- **計算方式**: 「割戻し計算」または「積上げ計算」（混合は不可）

**計算検証の手順:**
1. 記載されている税抜金額の合計を確認
2. 消費税額 = 税抜金額合計 × 税率（10% or 8%）を計算
3. 記載されている消費税額と比較
4. 差異がある場合、端数処理の方法を推定して異常値か判定

### Step 5: チェック結果の出力

以下のフォーマットで結果を出力する。


## Examples

**Example 1: 不備のある請求書**
Input:
```
請求書
エナベース株式会社 御中

品名: コンサルティング費用  100,000円
品名: 交通費              5,000円
合計: 105,000円
消費税: 10,500円
総計: 115,500円

発行日: 2026年3月15日
株式会社テスト商事
```

Output:
```
■ 総合判定: ❌ 不適格

■ 必須記載事項チェック:
  ① 発行者名称:           ✅ 株式会社テスト商事
  ② 登録番号:             ❌ 記載なし
  ③ 取引年月日:           ✅ 2026年3月15日
  ④ 取引内容:             ⚠️ 軽減税率対象品の区分なし
  ⑤ 税率区分・適用税率:    ❌ 税率の明記なし
  ⑥ 税率別消費税額:        ❌ 税率ごとの区分なし
  - 宛名:                 ✅ エナベース株式会社

■ 修正が必要な項目:
  1. 適格請求書発行事業者の登録番号（T+13桁）を追記してください
  2. 各品目に適用税率（10%/8%）を明記してください
  3. 消費税額を税率ごとに区分して記載してください
```

## Edge Cases

- **軽減税率対象品目が含まれる場合**: 食品や新聞等には8%が適用される。品目名から推定可能な場合は注意喚起する
- **簡易インボイス（レシート型）**: 小売業等は宛名省略可。ユーザーに事業形態を確認する
- **仕入明細書形式**: 買い手が作成する場合の要件は異なる旨を注記する
- **登録番号が読み取れない場合**: フォーマット不正として報告、国税庁サイトでの確認を促す

## Guidelines

- このスキルは法的助言を提供するものではない。最終判断は税理士や専門家に相談するよう必ず付言する
- 登録番号の有効性の最終確認は必ず国税庁の公表サイトを案内する
- 消費税の端数処理方法は事業者の選択に依存するため、「一般的には」という前提で判定する
- 免税事業者からの仕入れに関する経過措置（2029年9月30日まで）にも言及する
