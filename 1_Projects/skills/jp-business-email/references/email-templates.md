# 目的別メールテンプレート

## 依頼メール

```
件名: [依頼内容]のお願い

[宛名]

[挨拶文]

[背景説明 - 1〜2文]

つきましては、[依頼内容]をお願いしたく、ご連絡いたしました。

[具体的な依頼事項]

[期限がある場合]
誠に恐れ入りますが、[期日]までにご対応いただけますと幸いです。

ご多忙のところ恐縮ですが、何卒よろしくお願い申し上げます。
```

## お礼メール

```
件名: [案件名]のお礼

[宛名]

[挨拶文]

[タイミング] は [対応内容] いただき、誠にありがとうございました。

[お礼の具体的理由]

[今後について]

今後とも何卒よろしくお願い申し上げます。
```

## お詫びメール

```
件名: [案件名]に関するお詫び

[宛名]

[挨拶文]

[問題の内容] につきまして、多大なるご迷惑をおかけいたしましたこと、
心よりお詫び申し上げます。

[原因の説明]

[再発防止策]

今後このようなことがないよう、[具体的な改善策] を徹底してまいります。

重ねてお詫び申し上げますとともに、引き続きご愛顧を賜りますよう
よろしくお願い申し上げます。
```

## 催促メール

```
件名: [案件名]の進捗確認のお願い

[宛名]

[挨拶文]

[日時]にお送りいたしました[案件名]について、ご確認いただけましたでしょうか。

お忙しいところ恐縮ではございますが、[期限]までにご回答いただけますと
大変助かります。

なお、本メールと行き違いでご対応いただいておりましたら、
何卒ご容赦くださいませ。

よろしくお願い申し上げます。
```

## 案内・通知メール

```
件名: [案件名]のご案内

[宛名]

[挨拶文]

[案件名]について、下記の通りご案内申し上げます。

記

1. 日時: [日時]
2. 場所: [場所]
3. 内容: [内容]
4. 持ち物: [必要事項]

以上

ご不明な点がございましたら、お気軽にお問い合わせください。

よろしくお願いいたします。
```

## 断りメール

```
件名: Re: [元の件名]

[宛名]

[挨拶文]

[依頼/提案内容]について、ご連絡いただきありがとうございます。

大変申し訳ございませんが、[理由]のため、
今回は見送らせていただきたく存じます。

[代替案があれば記載]

ご期待に沿えず心苦しい限りではございますが、
何卒ご理解賜りますようお願い申し上げます。

また別の機会がございましたら、ぜひご相談させてください。
```
