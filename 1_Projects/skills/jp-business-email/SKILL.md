# 日本語ビジネスメール・マスター

日本のビジネス慣習に完全準拠した、プロフェッショナルな日本語ビジネスメールを生成するスキル。
敬語の3分類（丁寧語・尊敬語・謙譲語）を文脈に応じて正確に使い分ける。

## ワークフロー

### Step 1: コンテキストの把握

ユーザーから以下の情報を収集する。不足している場合は質問して確認する。

- **送信先**: 社外（取引先・顧客）/ 社内（上司・同僚・部下）
- **目的**: 依頼 / 報告 / お礼 / お詫び / 催促 / 案内 / 確認 / 初回挨拶
- **関係性**: 初対面 / 面識あり / 継続取引 / 上下関係
- **緊急度**: 通常 / 急ぎ / 至急
- **本文の要点**: ユーザーが伝えたいことの骨子

### Step 2: 敬語レベルの決定

以下のマトリクスに従って敬語レベルを決定する。

| 送信先 | 関係性 | 敬語レベル |
|---|---|---|
| 社外・取引先 | 初対面 | 最上級（謙譲語中心） |
| 社外・取引先 | 継続取引 | 上級（尊敬語＋謙譲語） |
| 社外・顧客 | すべて | 最上級（謙譲語中心） |
| 社内・上司 | すべて | 中級（丁寧語＋尊敬語） |
| 社内・同僚 | すべて | 基本（丁寧語） |
| 社内・部下 | すべて | 基本（丁寧語、やや砕けてもよい） |

### Step 3: メール構成

以下の構造でメールを組み立てる。

```
【件名】 [具体的で簡潔な件名]

[宛名]
[所属] [役職] [氏名]様

[挨拶文]

[本文]

[結語]

[署名ブロック]
---
[氏名]
[会社名] [部署名]
[電話番号]
[メールアドレス]
```

### Step 4: 挨拶文の選択

**季節の挨拶（社外向け・初回・改まった場面）:**
- 1月: 新春の候、貴社ますますご繁栄のこととお慶び申し上げます
- 2月: 余寒の候、貴社ますますご清栄のこととお慶び申し上げます
- 3月: 早春の候、貴社ますますご発展のこととお慶び申し上げます
- 4月: 陽春の候、貴社ますますご盛栄のこととお慶び申し上げます
- 5-6月: 時下ますますご清祥のこととお慶び申し上げます
- 7-8月: 盛夏の候、貴社ますますご隆盛のこととお慶び申し上げます
- 9月: 初秋の候、貴社ますますご繁栄のこととお慶び申し上げます
- 10月: 秋涼の候、貴社ますますご清栄のこととお慶び申し上げます
- 11月: 晩秋の候、貴社ますますご発展のこととお慶び申し上げます
- 12月: 師走の候、貴社ますますご隆盛のこととお慶び申し上げます

**汎用挨拶（社外向け・通常）:**
- 「いつもお世話になっております。」
- 「平素より大変お世話になっております。」

**社内向け:**
- 「お疲れ様です。」（同僚・部下）
- 「お疲れ様でございます。」（上司）

### Step 5: 目的別テンプレート適用

テンプレートの詳細は [references/email-templates.md](references/email-templates.md) を参照。

### Step 6: 最終チェック

以下の点を確認してからメールを出力する。

- [ ] 二重敬語になっていないか（例: ✗「ご覧になられる」→ ○「ご覧になる」）
- [ ] 「させていただく」の乱用がないか
- [ ] 「了解しました」を社外に使っていないか（→「承知いたしました」）
- [ ] 添付ファイルへの言及がある場合、「添付」の文言が含まれているか
- [ ] 件名が具体的で、相手が一目で内容を把握できるか
- [ ] 句読点（「、」「。」）が統一されているか

## よくある敬語の誤用と正しい表現

| ✗ 誤用 | ○ 正しい表現 | 備考 |
|---|---|---|
| ご覧になられる | ご覧になる | 二重敬語 |
| おっしゃられる | おっしゃる | 二重敬語 |
| 了解しました | 承知いたしました | 社外向け |
| ご苦労様です | お疲れ様です | 上司→部下でのみ使用可 |
| なるほど | おっしゃる通りです | ビジネスでは避ける |
| すみません | 申し訳ございません | 社外向け |
| 参考になりました | 勉強になりました | 目上の方に |
| わかりました | かしこまりました | 顧客向け |

## Examples

**Example 1: 取引先への依頼メール**
Input: 山田産業の佐藤部長に、来週の打ち合わせ日程を確認したい
Output:
```
件名: 来週のお打ち合わせ日程のご確認

山田産業株式会社
営業部 部長 佐藤様

いつもお世話になっております。
株式会社○○の△△でございます。

先日はお忙しい中お時間をいただき、誠にありがとうございました。

さて、来週のお打ち合わせの日程につきまして、ご確認させていただきたく
ご連絡いたしました。

下記の候補日時にて、ご都合のよろしい日をお知らせいただけますでしょうか。

　・3月18日（火） 10:00〜12:00
　・3月19日（水） 14:00〜16:00
　・3月20日（木） 10:00〜12:00

ご多忙のところ恐れ入りますが、今週末までにご回答いただけますと幸いです。

何卒よろしくお願い申し上げます。
```

**Example 2: 上司への報告メール**
Input: 課長に今月の売上が前月比120%だったことを報告したい
Output:
```
件名: 【報告】今月の売上実績について

○○課長

お疲れ様でございます。△△です。

今月の売上実績についてご報告いたします。

今月の売上は前月比120%を達成いたしました。
主な要因は以下の通りです。

　1. 新規顧客の獲得（3社）
　2. 既存顧客からのリピート注文増加
　3. キャンペーン施策の効果

詳細データにつきましては、別途資料をお送りいたします。

ご確認のほど、よろしくお願いいたします。
```

## Edge Cases

- **英語混じりの依頼**: IT用語など英語が多い場合、カタカナ語を適切に使用し、過剰な漢語化を避ける
- **相手の役職が不明**: 「ご担当者様」を使用し、ユーザーに確認を促す
- **CC/BCCの記載**: 複数名に送る場合、宛名に連名の書き方を適用（例:「佐藤様、田中様」）
- **返信メールの場合**: 件名に「Re:」を付け、引用ルールに準拠する
- **超長文の要件**: 要点を箇条書きにまとめ、詳細は添付資料で対応するよう提案する

## Guidelines

- ユーザーが署名情報を提供していない場合は、「○○」「△△」等のプレースホルダーを使用し、「署名部分はご自身の情報に置き換えてください」と添える
- 日時の候補は3つ提示するのが日本のビジネスマナー
- メールの長さは簡潔を心がけ、1スクロールで読める分量を目指す
- 添付ファイルがある場合は本文中で必ず言及する
