## 1. 下請法（取適法）の適用対象となる資本金・従業員基準マトリクス表

### 1.1 基本の適用基準（令和8年1月1日〜）

2026年1月1日から、**「下請法（下請代金支払遅延等防止法）」は「取適法（中小受託取引適正化法）」**に名称変更され、**従業員基準が新設**されました。[公正取引委員会](https://www.jftc.go.jp/file/toriteki_leaflet.pdf)

#### 【区分A】製造委託・修理委託・特定運送委託・プログラム作成・運送・倉庫保管・情報処理の場合

| 親事業者（委託事業者） | 下請事業者（中小受託事業者） |
|:---|:---|
| 資本金3億円超 **または** 従業員300人超 | 資本金3億円以下 **または** 従業員300人以下 |

#### 【区分B】その他の情報成果物作成委託・役務提供委託の場合

| 親事業者（委託事業者） | 下請事業者（中小受託事業者） |
|:---|:---|
| 資本金5千万円超 **または** 従業員100人超 | 資本金5千万円以下 **または** 従業員100人以下 |

**重要ポイント：**
- **いずれかの基準に該当すれば適用対象**（資本金基準と従業員基準は「または」の関係）[公正取引委員会](https://www.jftc.go.jp/file/toriteki_leaflet.pdf)
- 2026年1月1日以降は、資本金に関わらず従業員300人/100人超の事業者も親事業者として規制対象となる
- 従業員数の数え方：常時使用する従業員数（パート・アルバイト・派遣社員を含む）[公正取引委員会](https://www.jftc.go.jp/file/toriteki_leaflet.pdf)

### 1.2 取引内容別の適用範囲

| 取引内容 | 適用有無 | 備考 |
|:---|:---|:---|
| **製造委託** | ○ | 自社製品の製造委託が原則。ただし、販売を目的とする製造も含む |
| **修理委託** | ○ | |
| **プログラム作成委託** | ○ | |
| **特定運送委託** | ○ | 2026年1月1日から新たに追加[公正取引委員会](https://www.jftc.go.jp/file/toriteki_leaflet.pdf) |
| **物品の倉庫における保管** | ○ | |
| **情報処理** | ○ | |
| **その他の情報成果物作成** | ○ | プログラム以外の情報成果物（デザイン・文章など） |
| **その他の役務提供** | ○ | 建設工事、サービス業務など |

## 2. 親事業者の「4つの義務」と発注書チェックポイント

### 2.1 4つの義務の概要

親事業者には、下請取引の適正化を図るために以下の4つの義務が課されています。[公正取引委員会](https://www.jftc.go.jp/houdou/panfu_files/pointkaisetsu.pdf)

| 義務 | 法的根拠 | 内容 |
|:---|:---|:---|
| **① 発注書面の交付義務** | 第3条 | 発注時に取引条件を記載した書面を直ちに交付 |
| **② 支払期日の設定義務** | 第4条 | 受領日から60日以内かつできる限り短い期間内に支払期日を定める |
| **③ 取引記録の作成・保存義務** | 第5条 | 取引完了後、2年間書類等を保存 |
| **④ 遅延利息の支払義務** | 第6条 | 支払期日を過ぎた場合、年率14.6%の遅延利息を支払う |

### 2.2 発注書（3条書面）の記載必須事項チェックリスト

#### 【必須記載事項】（3条規則に基づく）

| No. | 記載事項 | 発注書での確認ポイント | AI検出キーワード |
|:---|:---|:---|:---|
| 1 | **親事業者及び下請事業者の名称** | 双方の正式な会社名・代表者名が記載されているか | 「発注者」「受注者」「委託者」「受託者」 |
| 2 | **委託をした日** | 発注日が明記されているか | 「発注日」「注文日」「委託日」 |
| 3 | **給付の内容** | 品名・規格・仕様が具体的に記載されているか | 「品名」「規格」「仕様」「数量」 |
| 4 | **給付を受領する期日（納期）** | 納品日・完了日が明確か | 「納期」「納入日」「完了日」「納品日」 |
| 5 | **給付を受領する場所（納入場所）** | 納品場所が記載されているか | 「納入場所」「納品場所」「受領場所」 |
| 6 | **検査を完了する期日** | 検査完了日が記載されているか | 「検査完了日」「検収日」「検品日」 |
| 7 | **下請代金の額** | 金額が具体的に記載されているか（算定方法でも可） | 「代金」「金額」「報酬」「単価」 |
| 8 | **支払期日** | 受領日から60日以内かつ具体的な日付が記載されているか | 「支払期日」「支払日」「振込日」 |
| 9 | **支払方法** | 現金・振込・手形などの支払方法が記載されているか | 「支払方法」「振込」「手形」「現金」 |
| 10 | **有償支給原材料等の詳細**（該当する場合） | 有償支給がある場合、品名・数量・対価・引渡期日・決済期日・決済方法が記載されているか | 「有償支給」「原材料」「材料費」 |
| 11 | **知的財産権の譲渡・許諾の範囲**（該当する場合） | 知的財産権を発注の内容に含む場合、その範囲が記載されているか | 「知的財産権」「譲渡」「ライセンス」「著作権」 |

#### 【注意事項】

- **特定事項が未定の場合**：当初書面に「未定の理由」と「予定期日」を記載し、後日「補充書面」を交付する必要がある[公正取引委員会](https://www.jftc.go.jp/shitauke/legislation/index_files/article3.pdf)
- **電磁的方法（電子メール等）による交付**：2026年1月1日から、相手方の承諾がなくても電子メールなどの電磁的方法による交付が可能となった[公正取引委員会](https://www.jftc.go.jp/file/toriteki_leaflet.pdf)

### 2.3 支払期日の設定チェックポイント

| チェック項目 | 適正 | 違反リスク |
|:---|:---|:---|
| **受領日からの日数** | 60日以内かつできる限り短い期間 | 61日以上の場合は違反 |
| **具体的な日付** | 「○月○日」など具体的な日付 | 「○日以内」「翌月末」などの曖昧な表現 |
| **受領日の定義** | 物品の受領日または役務提供日が明確 | 受領日の定義が不明確 |
| **支払方法** | 現金または振込（手形払は2026年1月1日から禁止） | 手形払、電子記録債権、ファクタリングなど |

### 3.2 2026年1月1日から新設・強化された禁止事項

#### 【新設】協議に応じない一方的な代金決定の禁止

2026年1月1日から、以下の行為が新たに禁止されました。[公正取引委員会](https://www.jftc.go.jp/toriteki_pointleaflet2.pdf)

- **中小受託事業者からの価格協議の求めに応じずに、一方的に代金を決定すること**
- **協議を明示的に拒む場合だけでなく、協議の求めを無視したり、繰り返し先延ばしにしたりして、協議を困難にさせる場合も違反**

**AI検出キーワード：**
- 「価格交渉には応じない」
- 「この価格で受けてくれないなら取引停止」
- 「価格はこちらで決定する」
- 「交渉の余地はない」

#### 【強化】手形払等の禁止

2026年1月1日から、以下の支払手段が禁止されました。[公正取引委員会](https://www.jftc.go.jp/toriteki_pointleaflet2.pdf)

- **手形による代金の支払い**（「支払遅延」に該当）
- **電子記録債権やファクタリングを使用する場合で、支払期日までに代金満額相当の現金を得ることが困難なもの**

**AI検出キーワード：**
- 「手形払い」
- 「約束手形」
- 「電子記録債権」
- 「ファクタリング」
- 「割引手形」
- 「満期日が支払期日より後」

**違反となる具体例：**
1. 製造委託等代金の支払期日よりも後に満期日が到来する場合に中小受託事業者において割引を受ける等の行為が必要なとき
2. 中小受託事業者に受取手数料等の負担が生じるとき

#### 【新設】振込手数料の受注者負担の禁止

2026年1月1日から、以下が禁止されました。[公正取引委員会](https://www.jftc.go.jp/toriteki_pointleaflet2.pdf)

- **中小受託事業者との合意の有無にかかわらず、振込手数料を中小受託事業者に負担させ、製造委託等代金から差し引くこと**（「減額」に該当）

**AI検出キーワード：**
- 「振込手数料は受注者負担」
- 「手数料を差し引いて支払う」
- 「手数料は受取側負担」

## 4. フリーランス新法と下請法（取適法）の比較

### 4.1 両法の適用範囲の違い

| 項目 | 下請法（取適法） | フリーランス新法（特定受託事業者に係る取引の適正化等に関する法律） |
|:---|:---|:---|
| **法的根拠** | 下請代金支払遅延等防止法（昭和30年法律第120号）<br>→2026年1月1日から「中小受託取引適正化法」 | フリーランス・事業者間取引の適正化等に関する法律（令和6年法律第49号） |
| **施行日** | 1955年（昭和30年）施行<br>2026年1月1日から改正（取適法） | 2024年11月1日 |
| **規制の対象者** | **資本金基準または従業員基準**で決まる<br>・親事業者：資本金3億円超または従業員300人超（製造等）<br>・下請事業者：資本金3億円以下または従業員300人以下 | **相手方が「特定受託事業者」**（従業員を使用しない個人または法人）<br>※発注者の規模は不問 |
| **規制の考え方** | 「資本規模」による強者・弱者の関係 | 「組織の有無」による強者・弱者の関係 |
| **対象取引** | 製造委託、修理委託、情報成果物作成委託、役務提供委託など | 業務委託全般（物品製造、情報成果物作成、役務提供） |
| **継続性の要件** | 単発取引でも対象 | 継続的な業務委託（1ヶ月以上）が原則 |
| **再委託の例外** | なし | あり（元委託者からの支払期日から30日以内） |

[BUSINESS LAWYERS](https://www.businesslawyers.jp/articles/1417)

### 4.2 支払期日に関する規定の違い

| 項目 | 下請法（取適法） | フリーランス新法 |
|:---|:---|:---|
| **基本ルール** | 受領日から60日以内 | 受領日から60日以内 |
| **遅延利息** | **年率14.6%の遅延利息支払義務あり** | 遅延利息の規定なし |
| **再委託の例外** | なし | あり（元委託者からの支払期日から30日以内） |
| **報酬額の減額** | 禁止 | 禁止 |

### 4.3 フリーランス新法特有の記載必須事項（3条通知）

フリーランス新法では、発注者がフリーランス（特定受託事業者）に対して業務委託をした場合、以下の事項を**書面または電磁的方法**で明示しなければなりません。[公正取引委員会](https://www.jftc.go.jp/fllaw_limited/fllaw_qa.html)

| No. | 記載必須事項 | 発注書での確認ポイント |
|:---|:---|:---|
| 1 | 業務委託事業者及び特定受託事業者の名称 | 双方の正式な名称 |
| 2 | 業務委託をした日 | 発注日 |
| 3 | 給付・役務の内容 | 業務内容の詳細 |
| 4 | 給付・役務提供の期日 | 納期・完了期日 |
| 5 | 給付・役務提供の場所 | 納入場所・実施場所 |
| 6 | **報酬の額及び支払期日** | 金額と具体的な支払日 |
| 7 | （検査をする場合は）**検査完了日** | 検査完了予定日 |
| 8 | （現金以外の方法で支払う場合）**支払方法に関すること** | 振込先口座情報など |

**フリーランス新法特有のポイント：**
- **報酬額**の記載が必須（下請法では「下請代金」）
- **検査完了日**の記載が必須（下請法では「検査完了期日」）
- **支払方法に関すること**が必須（現金以外の場合）

### 4.4 フリーランス新法と下請法の両方が適用されるケース

フリーランス新法と下請法は**重複して適用**されることがあります。[BUSINESS LAWYERS](https://www.businesslawyers.jp/articles/1417)

| ケース | 下請法（取適法） | フリーランス新法 | 適用結果 |
|:---|:---|:---|:---|
| 資本金3億円超の大企業が、従業員を使用しない個人事業者に製造委託 | ○ 適用 | ○ 適用 | **両法適用**（厳格な方の規制が適用） |
| 資本金1億円の中小企業が、従業員を使用しない個人事業者に業務委託 | × 非適用 | ○ 適用 | **フリーランス新法のみ適用** |
| 資本金5億円の大企業が、従業員10人の法人に製造委託 | ○ 適用 | × 非適用 | **下請法のみ適用** |

**重要ポイント：**
- 両法が重複して適用される場合、**厳格な方の規制が適用**される
- 下請法（取適法）には遅延利息（年率14.6%）の規定があるため、フリーランス新法のみが適用される場合よりも発注者の責任が重い

## 5. AIエージェント用 チェックポイントまとめ

### 5.1 発注書・契約書の自動チェック項目

#### 【ステップ1】適用対象判定

```
IF (親事業者の資本金 > 3億円 OR 親事業者の従業員数 > 300人) 
   AND (下請事業者の資本金 ≤ 3億円 OR 下請事業者の従業員数 ≤ 300人)
   AND (取引内容 = 製造委託 OR 修理委託 OR プログラム作成 OR 運送 OR 倉庫保管 OR 情報処理)
THEN 「下請法（取適法）適用対象」

IF (親事業者の資本金 > 5千万円 OR 親事業者の従業員数 > 100人)
   AND (下請事業者の資本金 ≤ 5千万円 OR 下請事業者の従業員数 ≤ 100人)
   AND (取引内容 = その他の情報成果物作成 OR その他の役務提供)
THEN 「下請法（取適法）適用対象」

IF (受注者が従業員を使用しない個人 OR 法人)
THEN 「フリーランス新法適用対象」
```

#### 【ステップ2】3条書面（発注書）の記載チェック

| チェック項目 | 合格基準 | 違反リスク |
|:---|:---|:---|
| 親事業者・下請事業者の名称 | 正式名称が記載されている | 記載なし・略称のみ |
| 委託日 | 具体的な日付が記載されている | 「近日中」「来週」など曖昧な表現 |
| 給付の内容 | 品名・規格・仕様が具体的 | 「など」「その他」などの包括的表現 |
| 納期・納入場所 | 具体的な日付・場所が記載されている | 「社内で調整」など曖昧な表現 |
| 下請代金の額 | 具体的な金額または算定方法が記載されている | 「別途協議」「実費精算」など |
| 支払期日 | 受領日から60日以内かつ具体的な日付 | 「翌月末」「○日以内」など |
| 支払方法 | 現金または振込（2026年1月1日以降は手形払禁止） | 「手形払」「電子記録債権」など |

#### 【ステップ3】11の禁止事項のリスクチェック

| 禁止事項 | 高リスクキーワード | 対応策 |
|:---|:---|:---|
| 買いたたき | 「値下げ要求」「コストダウン」「原価低減」 | 市価との比較検証 |
| 代金の減額 | 「減額」「値引き」「差し引き」 | 責任の有無の確認 |
| 支払遅延 | 「延期」「猶予」「待ってほしい」 | 受領日からの日数計算 |
| 受領拒否 | 「受け取れない」「納品拒否」 | 納期・納品実態の確認 |
| 不当返品 | 「返品」「返却」「在庫回収」 | 瑕疵の有無の確認 |
| 購入・利用強制 | 「指定購入」「自社製品購入」 | 正当な理由の有無 |
| 報復措置 | 「取引停止」「数量削減」「契約解除」 | 通報との因果関係 |
| 有償支給原材料等の早期決済 | 「早期決済」「差し引き」「相殺」 | 加工期間との整合性 |
| 不当な経済上の利益の提供要請 | 「協賛金」「寄付金」「無償派遣」 | 利益の不当性 |
| 不当な給付内容の変更 | 「仕様変更」「やり直し」「キャンセル」 | 費用負担の有無 |
| 協議に応じない一方的な代金決定 | 「一方的決定」「交渉拒否」 | 価格協議の経過 |

### 5.2 2026年1月1日以降の特別チェックポイント

| 新規・強化項目 | チェック内容 | 違反パターン |
|:---|:---|:---|
| **従業員基準** | 資本金に加えて従業員数（300人・100人）でも適用対象を判定 | 資本金は小さいが従業員数が多い企業が親事業者に該当 |
| **手形払等の禁止** | 手形、電子記録債権、ファクタリングの使用 | 手形払い、満期日が支払期日より後の手形 |
| **振込手数料の受注者負担禁止** | 振込手数料の差し引き | 「手数料は受取側負担」などの記載 |
| **協議に応じない一方的な代金決定の禁止** | 価格協議の要請に対する対応 | 価格協議を拒否・無視・先延ばし |

┌─────────────────────────────────────────────────────────┐
│  STEP 1: 適用対象判定                                    │

│  ├── 下請事業者の資本金・従業員数を確認                  │
