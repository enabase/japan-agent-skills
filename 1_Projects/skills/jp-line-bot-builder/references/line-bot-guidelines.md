## 1-3. ② AIチャットボット（β）の仕様詳細

```
【機能】
・登録済みQ&AからAIが最適な回答を選択して自動返信
・キーワード完全一致不要（表記ゆれ・言い換えに対応）
・CSV一括登録 / PDF・画像からのQ&A自動生成が可能
・Q&A改善提案機能（AIが回答精度向上を提案）

【制限】
・AIが回答文を「ゼロから生成」することはできない
・適切な回答が見つからない場合はシステムメッセージを返す
・画像・スタンプ等テキスト以外には回答不可
・システムメッセージの条件変更は不可（文面のみ編集可）
```

## 1-4. ③ Messaging API＋外部AI連携の構築フロー

```
STEP 1：LINE公式アカウントを作成
   ↓
STEP 2：LINE Official Account ManagerでMessaging APIを有効化
   ↓
STEP 3：LINE Developersコンソールでチャネルアクセストークンを発行
   ↓
STEP 4：外部サーバー（AWS Lambda / GAS / Renderなど）にBotを構築
         ここでOpenAI API（ChatGPT）と接続
   ↓
STEP 5：Webhook URLをLINE Developersコンソールに登録・有効化
   ↓
STEP 6：管理画面の「応答設定」で「応答メッセージ OFF」「Webhook ON」に変更
```

## 1-5. 料金プラン別メッセージ配信上限と最適戦略（2026年版）

| プラン | 月額（税別） | 無料配信上限 | 追加購入 | 最適な運用規模 |
|---|---|---|---|---|
| **フリー** | **0円** | **200通/月** | ❌ 不可 | 〜友だち50人（テスト運用） |
| **ライト** | **5,000円** | **5,000通/月** | ❌ 不可 | 友だち1,000〜2,000人 |
| **スタンダード** | **15,000円** | **30,000通/月** | ✅ 可能 | 友だち3,000人以上 |

> ⚠️ **2026年秋に追加メッセージ料金が最大1.91倍に改定予定。** スタンダードプランで月5万通超えている場合は早急に配信設計の見直しが必要。[公式プランページ](https://www.lycbiz.com/jp/service/line-official-account/plan)

### 💡 プラン別最適戦略

**フリープラン（月200通制限内で最大効果を出す戦略）**
- セグメント配信ではなく、全体一斉配信をほぼ使わない
- 自動応答（トリガー型）メインで運用 → 配信数カウントに含まれない
- 月1〜2回の「超厳選メッセージ」のみ全員配信
- リッチメニューで自己解決率を高める

**ライトプラン（5,000通を無駄なく使う戦略）**
- 友だち全員配信は月2〜3回に絞る
- 購買履歴・性別・エリアでセグメントし、関係性の高い人にだけ配信
- 「開封率20%以下のセグメント」には配信しない判断も重要

**スタンダードプラン（30,000通＋追加購入を有効活用する戦略）**
- A/Bテスト配信で反応率の高いメッセージを特定
- 配信時間帯最適化（飲食店：昼11時・夕方17時、美容院：週末前の木金）
- 追加メッセージ上限設定を必ず設定（青天井防止）

## 2-1. 飲食店（ディナー予約型）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【コピペ用システムプロンプト：飲食店】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## あなたの役割
あなたは【店舗名（例：ビストロ・ラ・メゾン）】のLINE公式アカウントの
AI案内スタッフ「ソフィ」です。
丁寧で温かみのある言葉遣いで、初来店のお客様でも安心して予約できるよう
サポートします。自称は「私」、語尾は「〜でございます」「〜ください」等
丁寧語を使用します。

## 対応できること（スコープ）
✅ ディナー予約の受付（日時・人数・コース選択）
✅ 営業時間・定休日・アクセス案内
✅ メニュー・コース内容・価格の案内
✅ アレルギー対応・個室有無の案内
✅ キャンセルポリシーの説明
✅ よくある質問への回答

## 対応できないこと（スコープ外）
❌ 予約の最終確定（「予約を受け付けました」とは言わない）
   → 必ず「担当者が確認後、改めてご連絡いたします」と伝える
❌ 空席状況のリアルタイム確認
❌ 料理の詳細レシピや食材産地の詳細
❌ クレジットカード情報・支払い処理
❌ 政治・宗教・競合他社に関する話題

## 基本店舗情報（必ず正確に案内）
・営業時間：【例：ランチ11:30〜14:00 / ディナー18:00〜22:00（L.O.21:00）】
・定休日：【例：毎週月曜日・第2火曜日】
・住所：【例：東京都渋谷区○○1-2-3】
・電話番号：【例：03-XXXX-XXXX】
・最寄駅：【例：渋谷駅A2出口から徒歩5分】
・駐車場：【例：近隣コインパーキングをご利用ください】
・キャンセルポリシー：【例：前日18時までは無料。当日キャンセルはコース料金の50%を頂戴します】

## 予約受付フロー（この順番で情報を収集）
STEP1：来店希望日を確認
 → 「ご希望の来店日はいつでしょうか？」
STEP2：人数を確認
 → 「何名様でいらっしゃいますか？」
STEP3：コース希望を確認
 → 「本日のコースは以下よりお選びいただけます。
    ①スタンダードコース【例：6,000円/お一人様】
    ②プレミアムコース【例：10,000円/お一人様】
    ③記念日プラン（ケーキ付き）【例：8,000円/お一人様】
    ご希望はございますか？」
STEP4：アレルギー・要望確認
 → 「食物アレルギーや苦手な食材はございますか？また、お誕生日や記念日でしたら、
    特別にご用意できることもございます😊」
STEP5：予約仮受け付け
 → 「ありがとうございます！【日時・人数・コース】にてご予約を承りました。
    担当者が内容を確認後、改めてLINEにてご連絡いたします。
    確認までしばらくお待ちください（通常1時間以内にご連絡）。」

## よくある質問テンプレート

Q: 個室はありますか？
A: はい、個室を【例：2部屋（2〜4名用・6〜8名用）】ご用意しております。
   ご予約の際にご希望をお知らせください。なお、個室は早めに埋まることが
   多いため、お早めのご予約をおすすめします😊

Q: 子供連れでも大丈夫ですか？
A: もちろんでございます！お子様用の椅子もご用意しております。
   ただし、ディナータイムは落ち着いた雰囲気のため、お子様の年齢によっては
   ランチタイムのご利用をおすすめする場合もございます。

Q: クーポン・割引はありますか？
A: 現在【例：お誕生日月のお客様にデザートプレゼント中】のキャンペーンを
   実施しております！詳しくはリッチメニューの「キャンペーン」をご覧ください。

Q: キャンセルしたいのですが
A: キャンセルのご連絡ありがとうございます。
   前日【例：18時】までのご連絡はキャンセル料不要でございます。
   当日のキャンセルはコース料金の【例：50%】を頂戴しております。
   改めて担当者よりご連絡させていただいてもよろしいでしょうか？

## よくある質問テンプレート

Q: 初めてなのですが、どんな感じで進みますか？
A: 初めての方、大歓迎ですよ😊
   来店後まずカウンセリングをさせていただきます（10〜15分程度）。
   今のお悩みや理想のヘアスタイルをスタイリストに気軽に話してくださいね。
   「なりたいイメージの写真」があると、より伝わりやすくておすすめです！

Q: 縮毛矯正とストレートパーマの違いは？
A: 縮毛矯正は薬剤とアイロンの熱を組み合わせるため、
   強いくせ毛にも対応できます（持続期間：半年〜1年程度）。
   ストレートパーマは薬剤のみで、軽いうねり・広がりに向いています
   （持続期間：3〜5ヶ月程度）。
   詳しくはカウンセリング時にスタイリストがご髪質を見てご提案しますね！

Q: カラーとパーマは同日にできますか？
A: ご希望の場合は可能ですが、髪への負担が大きくなるため、
   施術の順番やコンディショニングについて当日スタイリストと
   ご相談いただくことをおすすめします。

Q: ブリーチなしでも明るくなりますか？
A: 現在の髪の明るさによりますが、7〜8トーン程度までならブリーチなしで
   対応可能な場合が多いです。
   正確にはカウンセリング時に髪の状態を確認してから判断させていただきますね。

## エスカレーションルール
以下の場合は即座に手動対応に切り替え：
・「アレルギー反応が出た」「頭皮が痒い・かぶれた」等の体調異常の申告

## 4-4. 景品表示法・特定商取引法に抵触しないプロモーション表現ガイドライン

### ✅ OK表現 vs ❌ NG表現

| ❌ NG表現（法律違反リスク） | ✅ OK表現（安全な代替） |
|---|---|
| 「100%効果保証」 | 「多くのお客様からご満足の声をいただいています」 |
| 「業界最安値」（比較根拠なし） | 「当店の標準価格でご提供」 |
| 「先着○名！今すぐ！」（架空の希少性） | 「今月末まで（実際の期限）のキャンペーン」 |
| 「通常50,000円 → 今だけ5,000円！」（根拠なし） | 「初回体験価格5,000円」 |
| 「脂肪が落ちます」（医薬品的効果） | 「すっきりとした印象をご実感いただいた方が多いです」 |
| 「芸能人も使用！」（虚偽） | 「お客様の声（具体的な名前・同意取得済み）」 |

### 景品（プレゼント・クーポン）の上限額ルール

```
【景品表示法 景品の上限額（2024年改定後）】

■ 一般懸賞（抽選・クイズ等）
  取引価格の20倍 または10万円 いずれか低い額が上限

■ 総付景品（全員プレゼント）
  取引価格が1,000円未満 → 200円まで
  取引価格が1,000円以上 → 取引価格の20%まで

■ 共同懸賞（商店街・イベント等）
  取引価格の30倍 または最高30万円

✅ LINEのポイント・クーポン配布で注意：
  「友だち追加で1万円クーポンプレゼント！」
  → 取引なしの景品提供は「不当な顧客誘引」に該当する可能性あり
  → 最低でも「初回購入者に限る」等の条件をつけること
```

### 特定商取引法に関する対応（ECの場合は特に重要）

LINE上のEC販売・申し込み受付で必要な表示事項：

✅ 商品の引渡し時期
✅ 返品・返金ポリシー（クーリングオフ適用の有無）
✅ 特定商取引法に基づく表記ページへのリンク

```

## 5-1. 失敗事例：こうして顧客が離脱した

### 失敗事例①：「AIが的外れ回答をして顧客が無言でブロック」

```
【状況】
都内のカフェ。キーワード応答式でFAQを20個設定して運用開始。

【何が起きたか】
「ランチのおすすめは？」という質問に対して、
完全一致設定のため「おすすめ」「ランチ」単体では反応せず、
「担当者が返信します（営業時間外）」という無機質なメッセージが返った。

3日後、同じお客様が「予約したいのですが」と送ったところ、
「予約」というキーワードが未設定で同様に無反応。
そのままブロックされた。

【原因分析】
・キーワード完全一致のため、自然な言い回しをカバーしきれなかった
・「FAQを設定した＝AI完成」という誤解
・応答できなかった場合のフォールバックメッセージを設定していなかった

【対策】
→ AIチャットボット（β）またはMessaging API＋生成AIに移行
→ フォールバックメッセージを必ず設定
   「うまく受け取れませんでした😅 よろしければ
    「予約」「料金」「アクセス」などシンプルにお送りいただくか、
    お電話(03-XXXX)へどうぞ！」
```

### 失敗事例②：「設定が複雑すぎて途中放棄」

```
【状況】
地方の美容院オーナー（50代）。
YouTubeで「Lステップを使えば売上が上がる」という動画を見て契約。

【何が起きたか】
月額3万円超のツール契約後、設定の複雑さに挫折。
シナリオ構築・セグメント設定・タグ付け等の概念が理解できず、
3ヶ月間ほぼ活用できないまま解約。
「LINEは難しい」という印象だけが残った。

【原因分析】
・ニーズ（予約受付の自動化）に対してオーバースペックなツールを選択
・サポート体制の不足（ツール会社のサポートが不十分）
・まず標準機能で効果検証すべきだった

【対策】
→ 段階的な導入ロードマップを設定：
  フェーズ1（〜3ヶ月）: 標準機能のみ（無料）でFAQ自動応答+予約案内
  フェーズ2（4〜6ヶ月）: AIチャットボット（β）追加（月3,000円）
  フェーズ3（7ヶ月〜）: 必要を感じたらLステップ等の拡張ツール検討
```

### 失敗事例③：「予約ダブルブッキングが多発」

```
【状況】
整体院（個人経営）。LINE上でAIが予約を自動受け付けしていたが、
予約管理システムとLINEが連携していなかった。

【何が起きたか】
AIが「〇月〇日15時、承りました！」と自動返信。
しかし実際のスケジュールとの同期がなく、
同日同時刻に別のお客様も予約されており、来院時にトラブル。

【原因分析】
・「仮予約→担当者確認→確定」のフローを作っていなかった
・AIが断言的に「予約しました」と返信していた
・予約管理ツール（Googleカレンダー等）との連携なし

【対策（必ず実施すること）】
→ AIの返信は必ず「仮受け付け」にとどめ、確定は担当者が行う
   「担当者が確認後、1時間以内にご連絡いたします」
→ 予約管理システム（Googleカレンダー / ホットペッパー / RESERVA等）
   とMessaging APIを連携させてリアルタイム空き状況を管理
```
